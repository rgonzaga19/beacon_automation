CF4 Quick Guide

Run CF4 automation

  1. In Automation, enter one Beacon transmittal number per line. Blank lines are ignored.
  2. Switch on Include Auto Encode CF4 if you want Beabots to fill CF4 fields using your saved defaults.
  3. Select Start Automation and let the workflow finish. Keep the app open while it runs.
  4. Review the queue table for each transmittal and open the Automation log for processing details or errors.

Configure CF4 defaults

  1. Open Encoding defaults to edit the text and selections used when Auto Encode CF4 is enabled.
  2. Set admission details, pertinent symptoms, general survey, physical examination findings, and course in the ward to match your workflow.
  3. Select Save to keep your changes. Use Reset to defaults to restore the original values.

Before you start

  • Sign in to Beacon and make sure the transmittal numbers are correct.
  • Review your saved defaults before enabling Auto Encode CF4.
  • Run a manageable set of transmittals and check the report before continuing with more.

Review in Beacon

Automation results can require attention. Open the related claim in Beacon and verify the patient, transmittal, CF4 content, and any D.M. mapping before submitting. Correct missing or inaccurate information in Beacon.
