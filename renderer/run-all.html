File matching checklist
  1. Use the New Draft CF2 Excel template and include one completed patient row for each claim. Blank rows are ignored.
  2. Select exactly one SOA spreadsheet per completed patient row. The file count must match the row count.
  3. Name each SOA so it clearly identifies the patient, preferably surname followed by first name, such as ABAO ALLEN. A surname alone, such as ABAO, works only when it identifies one patient. Comma-formatted workbook names are normalized during the check.
  4. For patients with the same surname, add an initial or full first name. If needed, include a treatment date or day, such as ABAO AUG 13-15 or ABAO 15. Every selected file must match one patient only.
  5. Before any draft is created, Run All checks that the counts match and every patient has one unique SOA match. A missing, ambiguous, or duplicate match stops the run before processing begins.
  6. Choose the claim month and year used to interpret treatment dates. Billing contact fields are optional. CF4 uses your saved settings, or app defaults if none are saved.
  7. Run All creates claim drafts and encodes claim data in Beacon; it does not submit claims to PhilHealth.
