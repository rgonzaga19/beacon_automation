Before you start
  1. Use the New Draft CF2 Excel template and include one completed patient row for every claim.
  2. Select exactly one SOA Excel file per completed patient row. The totals must match; blank workbook rows do not count.
  3. SOA filenames may use the patient's surname or full name, but each file must match only one patient. Comma-formatted workbook names are normalized during preflight.
  4. Set the claim month and year used to interpret treatment dates. Confirm your saved CF4 settings are correct before starting.
  5. Run All creates drafts and encodes claim data. It does not transmit claims to PhilHealth.
