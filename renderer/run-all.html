How file matching works
  • The SOA file count must equal the number of completed patient rows.
  • Name each SOA with the patient's surname and first name, such as ABAO ALLEN.
  • If a match is missing, ambiguous, or duplicated, the run stops before any draft is created.
  1. Use the New Draft CF2 Excel template with one completed patient row per claim. Blank rows are ignored.
  2. A surname alone, such as ABAO, works only when it identifies one patient. Comma-formatted workbook names are normalized during the check.
  3. For patients with the same surname, add an initial or full first name. If needed, include a treatment date or day, such as ABAO AUG 13-15 or ABAO 15. Every selected file must match one patient only.
  4. The claim month and year interpret treatment dates. Billing contact fields are optional. CF4 uses your saved settings, or app defaults if none are saved.
  5. Run All creates claim drafts and encodes claim data in Beacon; it does not submit claims to PhilHealth.
